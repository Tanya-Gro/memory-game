# RS School: Memory Game

Интерактивная игра для тренировки памяти (поиск пар карточек), разработанная в рамках обучающей программы Rolling Scopes School.
👉 [Ссылка на ТЗ](https://github.com/rolling-scopes-school/tasks/tree/master/tasks/memory-game)

## Ссылка на деплой

👉 [Ссылка на приложение на Netlify](https://memory-game-rss.netlify.app/)

## Выполненные требования (Самооценка: 100 / 100 баллов)

- **Генерация разметки (15/15):** Вся разметка `<body>` генерируется динамически через `document.createElement` (использована кастомная функция-фабрика). Исходный HTML содержит только тег `<script>`.
- **Логика и механика игры (30/30):** Карточки перемешиваются алгоритмом Фишера — Йейта. Реализована блокировка поля при открытии несовпавшей пары (задержка 1000 мс). Повторные клики игнорируются.
- **Счетчики и статистика (5/5):** Ведется точный подсчет ходов и найденных пар.
- **Модальные окна (15/15):** Окна победы и таблицы лидеров используют общий переиспользуемый компонент. Закрываются кнопкой, кликом по фону или клавишей `Escape`.
- **Таблица лидеров (10/10):** Сохранение топ-10 результатов в `localStorage` с сортировкой по количеству ходов.
- **Новая игра (15/15):** Сброс состояния, обнуление таймеров и перетасовка полей происходят мгновенно без перезагрузки страницы.

## Фичи и улучшения

- Полное отсутствие сторонних зависимостей в рантайме (чистый Vanilla JS).
- Строгий статический анализ кода (ESLint v9 Flat Config + строгий `jsconfig.json`).
- Использование адаптивной CSS Grid сетки.
- Плавные 3D-анимации переворота карточек на чистом CSS (`perspective`, `backface-visibility`).

## Технологический стек

- **Runtime:** Vanilla JavaScript (ES6+ Modules)
- **Сборщик:** Vite
- **Линтинг/Форматирование:** ESLint, Prettier
- **Стилизация:** Адаптивный CSS3 (CSS Variables, Flexbox, Grid)

## Инструкция по локальному запуску

Для запуска проекта вам понадобится установленная среда [Node.js](https://nodejs.org).

1. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone https://github.com/Tanya-Gro/memory-game.git
   cd memory-game
   ```
2. Перейдите в ветку с проектом:
   ```bash
   git checkout memory-game
   ```
3. Установите зависимости:
   ```bash
   npm install
   ```
4. Запустите локальный сервер разработки:
   ```bash
   npm run dev
   ```
5. Откройте приложение в браузере по адресу, указанному в терминале (обычно это `http://localhost:5173`)
